## Ranked questions and follow-up boundaries

1. **Before any placement:** the catalogue owner and lead must settle exact foot, footprint, overhang, collision/support, aprons and interaction anchors for the reused families. Existing geometry envelopes are not those contracts. Candidate shared door/bridge/low-ledge records need regional applicability review; this report changes no biome tag or schema.
2. **Ground and route continuity:** source/end/tier data for Snowmelt Lake/Sleepwater, cave mouths, stair heads/feet and the valley seam must agree with the current authored plan. The older brief lists ramps, while shared_rock_cliff explicitly adds no general ramp and valley-plan describes stairs/no ramps on its own side. Preserve the existing data; the lead/assigned regional owner resolves the applicable connection rather than this report inventing one.
3. **Width/scale conflicts:** existing W02/3-cell aperture proposals, the older34-world-px stair minimum and the current size guide's art-px stair class measure different things. Do not silently choose, average or convert them into a new universal clearance. Each actual route/step/landing requires the named contract and source units. The12-world-px low-ledge proposal separately requires unsupported fractional-cell elevation; it remains blocked.
4. **Site assemblies:** tarn headwall, lookout, ice-cave mouth and any approved shelter instance need their own source-backed layout and gate evidence. No new single giant landmark PNG or placed prefab is specified here. Catalogue gaps mean a later brief, not permission to rebuild the shared catalogue.
5. **Conditional story and services:** Saddle House, Rime Wyrm arena/shard state and any speculative waystone event remain with their existing story/gameplay owners and required approval. Colour, source names or a proposed interact verb do not create support, travel, rewards or quests. Highgarth's post-town kit and closed-pass work are already separately owned and excluded.
6. **Art review:** once approved concepts and authored bindings exist, assigned workers draw to the existing house/Eastward direction, upper-left lighting, density3 scale, ground/water/route rules and source-appropriate geometry. Lead assembles applicable Y12/gate evidence; Matt approves the applicable PR. No biome palette, geology, wildlife or count is redesigned here.

## Validation and limits

This is a requirements report, not schema-valid concept intake or a runtime implementation. Source/blob and referenced-family/variant/approval checks plus document formatting and scoped whitespace are the light checks for this source step. Final full npm run verify with zero lint and ordinary npm run check:art-repro must be recorded separately on the frozen final head before readiness; their pending state must not be replaced with historical results or filtered hosted CI.

Raster/scene/cast detector numbers and same-height reference comparison are N/A to this text-only output, not a visual pass. No schema/library promotion, terrain evaluation, generated art, editor placement, rendered traversal, physical device, complete biome/wholeY19 or Matt approval is established. The lead reviews this source audit, resolves the bounded questions and assigns later non-overlapping work; no speculative values are implemented.
