# The whole build, in order, from a fresh save: the woodland, Crossroads, the Undercroft and back, to the
# closing card. The game is closed and started again after every step that moves the story (`restart`),
# and the player is downed once at each of the three fights. Commands: tools/play_driver.gd.

step a new game shows the title card and the first lead
wait 1.0
expect zone woodland
expect at 405 750 4
expect hp 5
expect banner The Starfall
expect hud Follow the path south
shot 01_opening

step the pause menu holds the game and lets go again
key Escape
expect paused yes
shot 02_pause
key Escape
expect paused no

step read the sign by the stones
goto 372 1150 10
expect prompt Read
talk StoneSign
expect said TO WHOEVER READS THIS
expect quest woodland_stones active clear_camp

restart
wait 1.0
expect zone woodland
expect quest woodland_stones active clear_camp
expect flag seen:opening
expect banner none

step downed at the camp: up again at the start with every heart, the quest kept, the camp whole

expect enemies 3
